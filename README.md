# Grace - IA de Atendimento ao Cliente

Projeto acadêmico de uma assistente virtual chamada Grace.

## Objetivo

A Grace foi criada para realizar o atendimento inicial aos clientes, responder dúvidas frequentes, fornecer informações sobre produtos e serviços e encaminhar situações que precisem de atendimento humano.

## Como testar

1. Baixe ou clone este projeto.
2. Abra o arquivo `index.html` em um navegador.
3. Digite uma pergunta no campo de mensagem.
4. Teste também os botões de perguntas rápidas.

## Publicar no GitHub Pages

1. Crie um repositório no GitHub.
2. Envie `index.html`, `style.css` e `script.js`.
3. Entre em Settings > Pages.
4. Em Build and deployment, escolha `Deploy from a branch`.
5. Selecione a branch `main` e a pasta `/ (root)`.
6. Salve e aguarde a publicação.

## Observação

Esta versão é um protótipo front-end. Ela não utiliza uma API de IA real. Para transformar a Grace em uma IA com respostas geradas por um modelo, será necessário conectar um backend seguro a uma API de IA e nunca colocar uma chave secreta diretamente no JavaScript do navegador.
